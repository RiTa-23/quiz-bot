# クイズ共有 Discord Bot 要件定義

## 1. 概要

クイズを作成・出題・管理できる Discord Bot。作成したクイズは自サーバー内限定の身内クイズとしても、他サーバーへの個別共有としても運用できる。クイズの作成・編集・削除は Discord 上のコマンドだけでなく Web アプリからも行える。

### 技術スタック
- Bot: Discord Hono
- Deploy: Cloudflare Workers
- Web: React + Hono
- DB: 未確定（Cloudflare D1 を想定、要検討）

---

## 2. 機能要件

### 2.1 クイズ作成
- 出題形式は以下の3種類から選択できる
  - **4択**（ボタン選択、Discord Components 使用）
  - **○×**（2択、ボタン選択）
  - **自由記述**（チャットでの回答を文字列一致等で判定）
- 1つのクイズは複数の設問（Question）を持てる
- 各設問には以下を設定できる
  - 問題文
  - 出題形式（4択・○×・自由記述）
  - 選択肢（4択の場合）
  - 正解
  - 解説（任意、出題後に表示）
- クイズ全体には以下のメタ情報を持つ
  - タイトル
  - 説明
  - 作成者（Discordユーザー）
  - 作成元サーバー（Discordサーバー）
  - 公開設定（サーバー限定 / 個別共有先）

### 2.2 クイズ出題
- 進行イメージは **単発出題**
  - コマンド実行時にクイズの中から1問（ランダム or 指定）を出題する
  - 複数問を連続で出す「セッション形式」は本フェーズでは対象外（将来拡張の可能性あり）
- 出題フロー
  1. ユーザーがコマンドでクイズ（または設問）を指定して出題を要求
  2. Bot が問題文・選択肢（該当形式の場合）を投稿
  3. ユーザーがボタン押下 or チャット送信で回答
  4. Bot が正誤判定し、正解・解説を表示

### 2.3 クイズ削除・編集（Discord コマンド）
- 作成者、またはクイズの編集権限を持つユーザーがコマンドから削除・編集可能
- 削除時は確認を挟む

### 2.4 Web アプリでのクイズ管理
- クイズの一覧表示・詳細確認
- クイズ・設問の作成・編集・削除
- 共同編集者の追加・削除（後述）

### 2.5 クイズの共同編集
- クイズごとに編集権限を持つ対象を指定できる
  - **サーバー指定**：指定した Discord サーバーのメンバー全員に編集権限
  - **ユーザー指定**：特定の Discord ユーザーに編集権限
- 権限レベル（例）
  - Owner（作成者、削除・共有設定変更含む全権限）
  - Editor（設問の追加・編集・削除は可能、共有設定や削除は不可）

### 2.6 クイズの共有・公開
- **デフォルト**：作成したサーバー限定（非公開）
- **個別サーバー共有**：作成者が特定の他サーバーを指定してクイズを共有できる
  - 共有されたサーバーはそのクイズを自サーバーで出題可能
  - 共有されたサーバー側からの編集は不可（別途 Editor 権限を付与しない限り）
- 全体公開（クイズストア的な一覧）は本フェーズでは対象外（将来拡張の可能性あり）

## 3. 認証・権限

- Web アプリは **Discord OAuth2** でログイン
- ログイン後、Discord アカウントの ID を軸に以下を判定
  - 自分が作成したクイズ
  - 自分が所属するサーバーが作成 or 共有を受けているクイズ
  - 自分が Editor として指定されているクイズ
- Bot 側のコマンド実行者も Discord ユーザー ID / サーバー ID をもとに同様の権限チェックを行う

### 権限マトリクス（案）

| 操作 | Owner | Editor | 共有先サーバーメンバー | その他 |
|---|---|---|---|---|
| 出題 | ○ | ○ | ○ | × |
| 設問の追加・編集 | ○ | ○ | × | × |
| クイズ削除 | ○ | × | × | × |
| 共有設定変更 | ○ | × | × | × |
| 共同編集者の追加・削除 | ○ | × | × | × |

## 5. API 設計（ドラフト）

Web アプリ（React）と Bot（Discord Hono）が共通のバックエンド API を利用する想定。

### 認証
- `GET /auth/discord` — OAuth2 開始
- `GET /auth/discord/callback` — OAuth2 コールバック、セッション発行

### クイズ
- `GET /api/quizzes` — 自分が閲覧・編集可能なクイズ一覧（作成分 + 共有分 + Editor 権限分）
- `POST /api/quizzes` — クイズ作成
- `GET /api/quizzes/:id` — クイズ詳細（設問含む）
- `PATCH /api/quizzes/:id` — クイズ情報更新（タイトル、説明、公開設定）
- `DELETE /api/quizzes/:id` — クイズ削除（Owner のみ）

### 設問
- `POST /api/quizzes/:id/questions` — 設問追加
- `PATCH /api/quizzes/:id/questions/:qid` — 設問更新
- `DELETE /api/quizzes/:id/questions/:qid` — 設問削除

### 共有
- `POST /api/quizzes/:id/shares` — 他サーバーへの共有追加（対象 guild_id 指定）
- `DELETE /api/quizzes/:id/shares/:shareId` — 共有解除

### 共同編集者
- `POST /api/quizzes/:id/editors` — 編集者追加（guild or user 指定）
- `DELETE /api/quizzes/:id/editors/:editorId` — 編集者削除

### 出題（Bot 内部から呼ばれる、または Bot 内で直接 DB アクセスする場合は不要）
- `GET /api/quizzes/:id/questions/random` — ランダム1問取得
- `POST /api/quizzes/:id/questions/:qid/attempts` — 回答結果の記録
